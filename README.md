# Simple Interest Calculator

This project is a simple interest calculator written in Bash.

## What it does

The script `simple-interest.sh` asks the user for:

- **Principal**: the initial amount of money
- **Rate of interest**: the annual interest rate (in %)
- **Time period**: the number of years

It then calculates the simple interest using the formula:

    Simple Interest = (Principal x Rate x Time) / 100

## How to run

    bash simple-interest.sh
